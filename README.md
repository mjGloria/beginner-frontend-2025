# FRC About Page Practice - Team 2658

## 🎯 Purpose
This is a practice project for learning React/Next.js basics. You'll create a simple "About Team 2658" page by filling in TODO sections.

## 📚 What You'll Learn
- Basic React/Next.js component structure
- JSX/TSX syntax
- HTML elements in React
- Project structure

## ✅ Your Task
Open `app/page.tsx` and fill in all the TODO sections:
1. Add a paragraph describing what Team 2658 does
2. Add a list of the four pathways
3. Add information about what FRC (FIRST Robotics Competition) is
4. Add any other sections you think would be good for an about page!
5. Add images to make it look nice

## 🚀 How to Run

### First Time Setup
```bash
npm install
```

### Run the Development Server
```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser to see your page!

## 💡 Tips
- Feel free to add more sections or styling!
- You can change the colors, fonts, and layout
- Try adding images or links
- Make it your own!

## 🆘 Need Help?
- The code uses TypeScript (.tsx), but you can write it just like regular JavaScript
- HTML tags work inside the `return ()` statement
- Comments in JSX use `{/* comment */}` syntax
- Save your file and the page will automatically reload!
